# 📚 **BookStore**

**Aplicação de Livraria Digital em JavaScript com foco em Programação Orientada a Objetos (POO).**  
Este projeto simula uma livraria digital onde é possível cadastrar produtos, autores, usuários, criar pedidos e gerenciar o estoque, tudo de maneira simples e eficaz. Utilizando conceitos de **POO**, como encapsulamento, herança e polimorfismo, buscamos criar uma estrutura modular e escalável.

---

## 🚀 **Tecnologias Utilizadas**

- **JavaScript (ES6+)**: O código foi escrito utilizando as mais recentes funcionalidades do JavaScript para garantir um código limpo e moderno.
- **Programação Orientada a Objetos (POO)**: Utilização de classes e objetos para representar entidades como `User`, `Author`, `Product`, etc.
- **Estrutura Modular**: O sistema foi organizado em módulos para facilitar a manutenção e a escalabilidade.
- **Persistência em Memória**: Os dados são armazenados em memória, simulando um banco de dados simples para fins de demonstração.

---

## 🧠 **Conceitos Aplicados**

Este projeto aplica de forma prática os pilares fundamentais da Programação Orientada a Objetos:

- **Encapsulamento**: Cada classe é responsável por encapsular seus dados e comportamentos, garantindo a integridade e o controle sobre os objetos.
- **Herança**: As classes `Book` e `Poster` herdam de `Product`, reutilizando código e estendendo funcionalidades.
- **Polimorfismo**: Métodos comuns entre produtos são sobrescritos de acordo com as necessidades de cada tipo de produto, como o cálculo de preço ou descrição.
- **Abstração**: A lógica da aplicação foi dividida em camadas, com a responsabilidade de cada uma bem definida, garantindo maior clareza e separação de interesses.
