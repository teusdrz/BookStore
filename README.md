# JS Bookstore

Aplicação de livraria digital em JavaScript com foco em Programação Orientada a Objetos.

## Tecnologias
- JavaScript (ES6+)
- Node.js (para testes, se houver)

## Estrutura
- src/classes: classes de domínio (User, Author, Product, etc.)
- src/Database.js: persistência em memória
- src/App.js: façade de operações

## Como usar
1. Clone o repositório.
2. Execute `node src/App.js` para rodar exemplos.
